# QCreates website

The source for [QCreates](https://q-creates.com/), a site for Qasem Abdeljaber's interior design consultation work. It presents the service, process, pricing, booking, and contact pages. The repository also contains earlier photography and computer science pages.

## Site structure

- `index.html` is the current interior design landing page.
- `bookPage.html` and `contact.html` provide the visitor paths from the landing page.
- `Styles/` contains the current page styles.
- `Photos/` and `CS-III/` hold photography and earlier project content.

The site is built with static HTML, CSS, and JavaScript. To inspect it locally, open `index.html` in a browser. Some paths and behaviors may depend on the deployed domain, so use the live site to verify the visitor experience.

The repository does not currently include a license file.
